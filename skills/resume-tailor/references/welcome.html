First run

Tailor the story, never the truth.

This skill maps a real job description to verified achievements, proven wording, and explicit format rules. It creates a resume draft for human review.

The workflow

1
Read the sourcesprofile.md owns facts; resume-style-guide.md owns presentation.
2
Analyze the listingExtract requirements, language, seniority signals, and honest gaps.
3
Build and renderReorder verified proof, export DOCX and PDF, and visually inspect every page.
4
Learn laterAfter submission, connect the exact positioning to the eventual outcome.

Hard boundary

No employer, responsibility, title, date, metric, credential, or public URL may be invented. Every automated resume remains Needs Human Review.
