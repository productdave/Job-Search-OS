# Resume QA criteria

A generated draft passes only when every hard requirement below passes. Style suggestions may be reported separately.

## Hard requirements

- Candidate name, employers, roles, dates, education, public links, and metrics match verified source material.
- No achievement, responsibility, credential, or result was invented.
- The target role and company match the listing being evaluated.
- Listing keywords are used naturally and truthfully.
- Every required experience block is present.
- The file follows `resume-style-guide.md`.
- DOCX and PDF both exist and correspond to the same revision.
- Every PDF page has been rendered and visually inspected.
- There is no clipping, overlap, unreadable text, broken link, malformed character, accidental blank page, or orphaned heading.
- Draft status remains `Needs Human Review`.

## Verdict

- `PASS`: all hard requirements pass.
- `FAIL`: one or more hard requirements fail.
- `FLAGGED — ATTACHED`: a human-authored or attached draft has an issue; report it without regenerating or overwriting it.

The QA pass does not approve an application for submission.
