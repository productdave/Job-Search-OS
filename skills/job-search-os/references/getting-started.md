# Getting started with Job Search Harness

Use this guide when someone is new and asks how to begin. Teach the steps in plain language before collecting their job-search details. If they only want a tour, stop after the walkthrough. If they ask to set up the harness and you can work with local files, continue with the onboarding in `job-search-os/SKILL.md`.

Job Search Harness is a repeatable way to find real openings, explain which ones fit, prepare truthful resume drafts, track applications, and learn from outcomes. The person chooses which roles to pursue, reviews every draft, and applies themselves.

## The first session, step by step

1. **Choose an AI app that can work with files.** A normal chat with the public connector can teach the method, but it cannot open or update a private folder on your computer. To run the full harness, open the [public toolkit](https://github.com/productdave/Job-Search-OS) in an AI agent that can read and write local files. The [visual onboarding guide](https://productdave.github.io/Job-Search-OS/) explains the setup without requiring technical knowledge.
2. **Keep your search in a separate private folder.** The public toolkit contains reusable instructions. Your resume, achievements, preferences, applications, and outcomes belong in your own private workspace, outside the public repository. Never commit that workspace to the public GitHub repo.
3. **Tell the agent your starting point once.** Share an existing resume if you have one. The agent should ask one focused group of questions about your target roles, locations, compensation, exclusions, verified achievements, and recent search results. You can say “I don't know yet”; uncertain facts stay marked as questions.
4. **Review what the agent sets up.** It creates a profile of verified facts, search preferences, operating instructions, and one primary tracker. Check that your achievements are accurate, the role filters reflect what you want, and the tracker is somewhere you can use. Correct anything that feels wrong before searching.
5. **Run one manual search together.** Ask for a short list of roles. The agent must check each promising role on the employer's own careers page or applicant tracking system, explain fit and concerns, and record confirmed roles in the primary tracker. Review the list and tell the agent which roles to pursue or pass on.
6. **Prepare drafts only for roles you choose.** Ask the agent to tailor a resume using verified facts, then check the finished pages and claims. Treat each resume as a draft until you approve it. You decide when and where to apply; the harness does not submit applications or send outreach for you.
7. **Feed the result back.** After an application, reply, rejection, or interview, tell the agent what happened. It records the outcome and updates its hypotheses. Repeated evidence can change future searches and positioning. Start any recurring schedule only after the manual search and draft process works for you.

## Messages you can use

**To learn in a chat with the public connector:**

> Teach me Job Search Harness step by step. Load the getting-started method, explain what I do and what the agent does, and show me the first manual run. Do not ask for my personal files in this chat.

**To begin in a file-capable agent with the toolkit open:**

> Start my Job Search Harness onboarding. Show me the guide, teach me the steps in plain English, then use my existing resume and one focused set of questions to set up a separate private workspace. Let me review the facts and search settings before the first manual run. Do not apply or contact anyone for me.

After setup, ordinary requests are enough: “Find and verify roles for today,” “Prepare a draft for this role,” or “Update the harness with this outcome.” The agent should read your current private workspace each time.
