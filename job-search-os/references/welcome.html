    Step 1 · Start here

    Let's get you set up.

    First, choose an AI agent that can work with files. Then we'll install the toolkit, set up a private folder, and run one search. You can go back to any step.

    Before you start

    1. Use the computer where you want to keep your job-search files.
    2. Open an AI agent that can read and edit files.
    3. Keep your personal files out of the public toolkit folder.
    4. Have a resume handy if you have one.
    Step 2 · How it works

    Here's the workflow you'll follow.

    Set your direction during setup. On each run, the agent reads your current files before searching or drafting.

    01 · SET THE SEARCH

    Tell it what you want

    Give the agent your target roles, locations, pay, strengths, and limits.

    02 · CHECK OPENINGS

    Review the shortlist

    Ask the agent to verify promising jobs on the employer's application page before it records them.

    03 · PREPARE A DRAFT

    Choose a role

    Ask for a tailored resume only when a role interests you. Check every claim in the draft.

    04 · RECORD THE RESULT

    Share what happened

    After an application or interview, add the outcome so the next search has that context.

    Step 3 · Set boundaries

    Keep your files private and check the work.

    Ask the agent to create a separate folder for your resume, profile, tracker, and drafts. Review what it saves before you run a search.

    Things for you to review

    • Your profile and career facts
    • Your target roles and search limits
    • Each shortlist and resume draft
    • Every application before you send it

    Things the agent can prepare

    • A list of verified openings
    • Notes on fit and concerns
    • Resume drafts for your review
    • A record of roles and outcomes
    Keep the folders separate. Don't add personal files to the public GitHub repository. The read-only connector serves public instructions; it can't work in your private folder.
    Step 4 · Choose an agent

    Choose an agent that can edit files.

    Use it on the computer where your private folder will live. Check that it can open a folder, read a file, and save a new one before you continue.

    Direct install

    ChatGPT Codex

    Open Codex on your computer. It can install the toolkit and create your private folder.

    Open a folder

    Claude Cowork or Code

    Download the toolkit, then give Claude access to that folder.

    Open a folder

    Cursor or VS Code agent

    Open the toolkit in the editor and give its AI agent permission to read and edit files.

    Using a normal ChatGPT or Claude chat? You can ask the read-only connector to explain the method. To set up and run the harness, use an agent with access to your private files.

    Step 10 · First manual run
    Run one search and check the roles.
    Once you've reviewed your profile and search settings, copy this message. The agent should give you a short list with a link to each employer's application page.
    
        
    Find today's roles
    Run my Job Search Harness for today. Read my current goals and recent feedback in my private workspace first. Find roles that fit, confirm each is open on the employer's application page, and update my primary tracker. Give me a short list with links, reasons for each match, and anything uncertain. Stop there. Don't draft resumes or apply to anything.
    
        
    Your primary tracker is the one place your agent records roles and outcomes. Check the shortlist and that record before choosing a role to pursue.
    
      
    
    
    

    
    
      
    Step 11 · Prepare and check
    Create and check resume drafts.
    Tell the agent which roles you want to pursue and ask it to mark them in your tracker. Then send the first message to make drafts. When they're ready, send the second to check the facts and finished pages.
    
        
    
          
    1. Prepare a draft
    Use the verified roles you chose and only facts you've confirmed.
    Run my separate resume-tailoring pass for roles I've marked to pursue that also meet the rules in my primary tracker. Use only facts I've confirmed. Save each draft as Needs Human Review. Don't apply or write cover letters.
    
          
    2. Check the draft
    Have the agent check claims and PDF pages, then review it yourself.
    Run the separate resume-QA pass on the latest drafts. Check every claim against my verified facts and inspect every PDF page for layout. Record the results in my primary tracker. Leave each draft as Needs Human Review.
    
        
    
        
    "Needs Human Review" means the draft isn't ready to send until you've checked and approved it.
    
      
    
    
    

    
    
      
    Step 12 · Keep learning
    Record the outcome before your next search.
    After you apply, hear back, or finish an interview, tell the agent what happened. It can use that record the next time you search.
    
        
    Share an outcome
    Record this outcome in my Job Search Harness: [TELL IT WHAT HAPPENED]. Tell me what it changes about the next search, and what you still aren't sure about.
    
        
    Once the search, drafting, and review steps work for you, you can ask your agent about a recurring schedule. Keep the same private workspace and tracker.
    
        
    Can the harness apply for me?
    No. Review the role and the draft, then submit the application yourself.
    
        
    Will it guarantee I pass an ATS?
    No. Check the draft for accurate facts and language that fits the role.
    
        
    How do I update an existing installation?
    Refresh the public toolkit and ask your agent to compare the new instructions with your private workspace. Keep your profile, tracker, and search settings. Follow the update instructions before changing a scheduled run.
