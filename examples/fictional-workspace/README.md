# Fictional example workspace

Everything in this directory is invented for demonstration:

- **Jordan Lee** is a fictional candidate.
- Northstar Labs, Harbor Analytics, and Lattice Harbor are fictional companies.
- All URLs use the reserved `.invalid` domain.
- All achievements, metrics, compensation, application events, and outcomes are fictional.

Do not use these facts in a real application. Generate a blank workspace from the canonical templates instead:

```bash
node ../../job-search-os/scripts/setup-workspace.mjs ../../my-job-search
```

## What this example demonstrates

- a profile with traceable achievement IDs and metric notes;
- explicit search constraints and a 10-point scoring rubric;
- a tracker with live, below-threshold, and needs-verification examples;
- hypotheses that remain separate from confirmed patterns;
- a keyword ledger that connects a submitted resume to an outcome;
- one-source-of-truth runtime thresholds.
